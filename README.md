# One-Liner Marathon — Entry

A single original one-line joke, generated by `main.ts` (Node ≥ 22, stdlib only).
Running the program writes the joke to `entry.txt` in the output directory
(`MAKEFUN_OUTPUT_DIR`, default `/output`).
